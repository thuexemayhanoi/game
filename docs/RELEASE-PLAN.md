# RELEASE PLAN

- Continuous deployment: GitHub Pages from verified main builds only
  (https://thuexemayhanoi.github.io/game/). Pages deploys are blocked when required CI fails.
- Releases tracked in docs/matrix/release-matrix.csv.
- Web first. Native (Android AAB, iOS, Windows, Linux, macOS) after M12 stabilization:
  store icons, splash screens, release configuration, signing documentation, lifecycle tests.
- Versioning: MAJOR.MINOR.PATCH; tag releases; artifacts attached to GitHub releases.
