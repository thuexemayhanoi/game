# ASSET POLICY

All game IP must be original. Do not copy any game's (including Flappy Bird's and GTA's) maps,
characters, logos, code, sprites, sounds, music, models, level layouts, or branding.
The one-button endless-obstacle genre is generic; all concrete expression in MOTO HOP
is original: procedural _draw() art and runtime-generated PCM audio.

## Early development

Use primitives, generated geometry, original placeholders, or permissively licensed
(CC0/CC-BY/MIT) assets only. No unlicensed commercial-game assets.

scripts/validate_assets.py checks: missing assets, suspiciously huge assets, unsupported
paths, case-sensitive filename problems, undocumented external assets.
